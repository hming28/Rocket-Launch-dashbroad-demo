# AETHER-9 工程版 · 多视图任务控制台 实现方案

> 交付对象:负责实现的 AI。日期:2026-10-31。前置文档:《底部动态仪表盘重构方案》(下称「主方案」)和《工程版仪表盘布局编辑器 实现方案》(下称「布局方案」)。本文档只改变**工程版**的信息架构,公众版不变。

## 0. 摘要

**一句话**:工程版新增「控制台模式」:一个按岗位分工的多视图界面(总览 + 5 个岗位视图),配套 3D 相机预设、偏差显示、趋势图和分级报警。原来的底部仪表盘保留,改称「紧凑模式」。

### 0.1 调研发现如何落地

| # | 调研发现 | 本方案的落点 |
| --- | --- | --- |
| 1 | 真实控制室按岗位分工,飞行主任逐席位点名 GO/NO-GO | 总览 + 5 个岗位视图;GO/NO-GO 席位板与事件前自动点名(§6.1、§8.2) |
| 2 | 轨迹看「名义曲线 + 实时点」,参数看相对名义值的偏差,带事件刻度和限制线 | 走廊图 CorridorPlot;各参数显示偏差(§4.3、§5.2) |
| 3 | 显示器必须标明数据是否还在更新 | LIVE / PAUSED / STALE 指示和过期报警(§4.6) |
| 4 | 有「选项与余量」专用图 | 回收视图的制动余量曲线(§6.6) |
| 5 | ISA-101:四层信息架构、模拟量条加趋势线、异常才用色 | 四层架构(§2.2)、AnalogBar(§4.1)、色彩规则(§3) |
| 6 | 报警要少、分级、每条都对应动作 | 报警引擎(§8.1) |
| 7 | 自定义要受限;趋势图要有限值线和叠加 | 控制台 v1 不开放自定义;StripChart 带限值线与名义叠加(§4.4) |

### 0.2 已确认的前提

- **P1**:公众版保持简单;工程版允许占用更多屏幕,不再受「细节只放底部」的限制。
- **P2**:「多视角」= 3D 相机预设 + 岗位数据视图,两者都做。
- **P3**:颜色只用于异常。正常状态用中性色,所以工程版比现在更克制。

**P4**:工程版可以自定义布局,但只在设置里的「布局编辑器」中选择和替换,不在飞行画面拖放;公众版不开放自定义(只有 4 个安全选项)。详见第 13 节。

## 1. 目标与非目标

**目标**

1. 工程师能在一屏内看清整体状态(总览),再钻进某个专业视图(岗位视图),再看到单个部件(部件页)。
2. 关键量都以「偏差」「余量」「趋势」呈现,不只是大数字。
3. 数据新鲜度、报警原因和建议动作随时可见。
4. 3D 视角可以切换,并可按飞行阶段自动导播。

**非目标**:真实 3D 场景(仍是占位,只定义相机接口)、飞行画面上的拖放自定义、GPU 流体、导出文件、联网数据源。

## 3. 视觉与色彩规则(工程版)

### 3.1 色板

| 用途 | 色值 | 说明 |
| --- | --- | --- |
| 背景 | `#05070B` | 面板底 `rgba(5,7,11,.78)` |
| 主文字 | `#F4F7FA` | 数值 |
| 次文字 | `#8A94A3` | 标签、单位 |
| 弱线条 | `rgba(255,255,255,.14)` | 刻度、网格 |
| 焦点/选中 | `#4FD1FF` | **只**用于「当前选中的标签、当前阶段、光标、交互焦点」,不表示状态 |
| 注意 | `#FFB020` | 异常:注意级 |
| 危险 | `#FF4D5E` | 异常:临界级 |

### 3.2 状态编码

| 状态 | 编码 |
| --- | --- |
| 正常 | 中性色(白/灰),**没有彩色** |
| 注意(P3) | 黄色 + `▲` 图标 + 文字 |
| 警告(P2) | 黄色 + `◆` 图标,面板标题行显示黄色小条 |
| 临界(P1) | 红色 + `■` 图标,允许闪烁 3 次后常亮 |
| 过期 STALE | 灰色斜线填充 + 文字 `STALE` |
| 仿真/派生数据 | 右上角小徽标 `SIM` 或 `派生`,灰色 |

### 3.3 禁忌

1. 正常数值、正常发动机、正常曲线不得使用青/绿/黄/红。(发动机点火用白色实心,故障用红色加叉。)
2. 颜色不能单独表达含义,必须同时有图标或文字。
3. 不使用渐变填充条、发光、毛玻璃。热流色条例外(黑体色是物理量的编码,不是状态)。
4. 动画只用于:阶段切换、报警出现、光标移动。数值变化不做动画。

## 4. 可视化组件

所有图表用 `canvas`(2D),按 `devicePixelRatio` 缩放(上限 2);数据刷新 10 Hz,重绘只在面板可见时进行。

### 4.1 AnalogBar(模拟量条)

- 横条高 12px;下方 5 个刻度;**名义值标记**(▽)落在条上方;限值用刻度上的短竖线(注意、临界各一条)。
- 填充为中性色;数值进入注意/临界时,**填充和数值文字**变黄/红并带图标。
- 右侧数值(16px)、单位(11px);其下一行小字:偏差徽标(§4.5)。
- 旁边 80×20px 的 Sparkline,显示最近 60 秒。

### 4.2 Sparkline

最近 60 秒、1 点/像素,当前点加一个小圆点。注意/临界时线条同色。无坐标轴。

### 4.3 CorridorPlot(走廊图)

- 用途:显示「应该在哪里、实际在哪里」。默认两张:**高度–速度**、**高度–时间**。
- 绘制:名义曲线(灰实线);容差带(同一曲线两侧的浅灰带,宽度见 §5.3);事件刻度(在名义曲线上,MAX-Q、MECO、分离、再入点火、着陆点火各一个短刻度加文字);**名义位置标记**(空心圆,沿名义曲线按当前 t 移动);**实际轨迹**(白色实线,到当前点);实际位置(实心圆)。
- 偏差:实际点离开容差带时,该段轨迹变黄,离开 2 倍带宽变红,并在右上角显示 Δ 数值(如 `Δv −212 m/s`、`Δh −1.3 km`)。
- 右下角显示数据新鲜度小点。
- 悬停显示该 t 的名义值与实际值。

### 4.4 StripChart(趋势图)

- 窗口两种:**最近 60 秒滚动**、**全程 0–428 秒**(带当前进度竖线)。
- 最多 3 条曲线叠加;名义曲线用虚线叠加在实际曲线之后。
- **限值线**:横向虚线加标签(例如 `动压限值 35 kPa`),注意/临界各一条。
- 事件竖线:Max-Q 窗口用浅灰带标出;MECO、分离等用细竖线。
- 光标:鼠标悬停显示竖线和各曲线的值;**所有同视图图表的光标同步**。
- 性能:全程数据最多 428 秒 × 10 Hz = 4280 点/曲线,绘制时按像素抽稀。

### 4.5 DeviationBadge(偏差徽标)

格式 `Δ +1.2%` 或 `Δ −212 m/s`。在容差内为灰色;超出为黄色(含 `▲`),超出 2 倍为红色(含 `■`)。名义值不可用时不显示。

### 4.6 FreshnessIndicator(新鲜度)

- 顶栏右侧:`LIVE ● 10 Hz`(运行中)、`PAUSED`(暂停,灰色)、`STALE`(过期,黄色加图标)。
- 每个面板右下角有一个小点,随数据更新轻微闪动。
- 过期判定:**实时**超过 1 秒没有收到仿真更新(暂停不算过期)。提供测试钩子 `setStale(true)` 用来演示,并触发 A10 报警(§8.1)。

### 4.7 复用的现有组件

`EngineMatrix`(发动机矩阵,含点击设故障)、`MarginBoard`(任务裕度条,改成 AnalogBar 样式)、线性时间轴、事件日志、小地图。

## 5. 数据与模型改动

### 5.1 总览

| 编号 | 改动 | 说明 |
| --- | --- | --- |
| M1 | Max-Q 节流深度 | 沿用主方案 §7:窗口 64–92 s,深度 30%;**属于名义剖面** |
| M2 | 过载 `nG` | `nG = (kN + drag) / (mass × 9.81)` |
| M3 | 二级发动机脚本 | 沿用主方案 §7,标 `SIM` |
| M4 | **名义 / 实际分离** | 新增 `S_nom(t)`(纯函数,不受故障影响)和 `S_act`(受故障与偏差影响) |
| M5 | **偏差积分** | 见 §5.2 |
| M6 | **历史缓冲** | 见 §5.4 |
| M7 | **派生量** | 见 §5.5 |

### 5.2 偏差模型(一阶近似)

名义推力 `kN_nom(t)` 含计划内的 Max-Q 节流;实际推力 `kN_act(t)` 另含发动机故障和用户注入的推力偏差。

- 推力比 `r(t) = kN_act / kN_nom`(`kN_nom = 0` 时取 1)。
- 名义推进加速度 `a_p(t) = kN_nom / mass_nom`(m/s²)。
- 速度偏差:`de_v/dt = (1 − r) × a_p`;`e_v` 累积,不自行恢复。
- 高度偏差:`de_h/dt = −e_v`。
- 实际值:`v_act = v_nom − e_v`,`alt_act = alt_nom − e_h`。`alt_act` 下限为 0。
- 只在**推力工作时**(`kN_nom > 0`)积分;滑行期 `e_v` 保持,`e_h` 继续按 `−e_v` 增长。
- 重置时 `e_v = e_h = 0`。推进剂关键帧不随偏差变化(已知简化,在界面 `派生` 提示里说明)。

**用户注入**:工程抽屉「调参」页新增一个滑块「推力偏差 −15%…+5%」,从注入时刻起对 `r` 乘以 `(1 + x)`。

**验收基线**:单台外圈发动机在 t=6 s 故障,t=150 s 时 `e_v` 应约 −350 m/s(误差 ±15%)。实现者应在实现后实测这个值并记为回归基线,不要照抄本文数字。

### 5.3 容差带

| 量 | 带宽 | 超出 2 倍带宽 |
| --- | --- | --- |
| 高度 | ±5%(最小 ±300 m) | 报警升一级 |
| 速度 | ±4%(最小 ±20 m/s) | 报警升一级 |
| 事件时刻(MECO 等) | ±2 s | — |

### 5.4 历史缓冲

用 `Float32Array` 环形缓冲,10 Hz、全程 4280 点,覆盖 12 个序列:`alt`、`v`、`thrust`、`nG`、`q`、`mach`、`heat`、`prop`、`pitch`、`rate`、`brakeMargin`、`ctrlAuth`;另存名义对应序列(同样 12 个)。重置清空。

### 5.5 派生量(界面一律带 `派生` 徽标)

| 量 | 公式 |
| --- | --- |
| LOX / RP-1 分量 | 按混合比 2.56 从总推进剂拆分:LOX = 71.9%,RP-1 = 28.1% |
| 燃烧室压力 | `97 bar × 节流比 ×(点火台数是否正常)` |
| 累计热载荷 | `∫ heat dt`(MJ/m²) |
| 预计触地时刻 ETA | 着陆点火后用 `alt / v` 估算 |
| 预测落点偏差 | 由 `e_v`、`e_h` 外推 |

限值阈值统一按**名义峰值**计算:启动时用 `S_nom` 扫描一遍全程得到 `q`、`nG`、`heat` 的名义峰值,注意 = 峰值 × 1.25,临界 = 峰值 × 1.5(`nG` 另有绝对限值 4.5 注意、5.5 临界)。

## 8. 报警与 GO/NO-GO

### 8.1 报警引擎

数据结构 `alarm = {id, rule, priority(1–3), root, state(active/ack/cleared), tRaised, tCleared, msg(zh,en), advice(zh,en), respondWithin(s)}`。

| 规则 | 条件 | 优先级 | 根因 root | 建议动作 | 响应时限 |
| --- | --- | --- | --- | --- | --- |
| A01 发动机故障 | 计划内有 `fl` | 1 台 P2;≥3 台或着陆段中心故障 P1 | ENG | 检查推力与推重比 | 10 s |
| A02 控制权限低 | <50% / <30% | P3 / P2 | 有故障则 ENG,否则 GNC | 评估姿态余量 | 15 s |
| A03 推进剂余量 | <5 t / <0 | P3 / P1 | PROP | 评估回收预留 | 10 s |
| A04 过载 | ≥4.5 G / ≥5.5 G | P3 / P1 | LOAD | 评估节流 | 5 s |
| A05 动压 | >名义峰值×1.25 / ×1.5 | P3 / P2 | LOAD | 评估节流 | 10 s |
| A06 热流 | >名义峰值×1.25 / ×1.5 | P3 / P2 | LOAD | 评估再入姿态 | 10 s |
| A07 制动余量 | <150 m / <50 m / <0 | P3 / P2 / P1 | REC | 保持满推力 | 5 s |
| A08 轨迹偏差 | 持续 >3 s 出带 / 出 2 倍带 | P3 / P2 | FIDO | 评估落点 | 20 s |
| A09 预测触地过载 | >4.5 G | P2 | REC | 检查缓冲行程 | 10 s |
| A10 数据过期 | STALE | P2 | DATA | 检查数据链路 | 5 s |
| A11 ABORT | 已触发 | P1 | ABORT | — | — |
| A12 席位 NO-GO | 任一席位 NO-GO | P3 | 对应席位 | 按席位提示 | 事件前 |

**行为规则**

1. **根因合并**:同一 `root` 已有活跃报警时,新报警并入该条,显示「衍生 +n」。同一规则 5 秒内只触发一次;条件消失需持续 ≥2 s 才清除(回差)。
2. 新的 P1/P2 在状态条的计数上闪动一次;P1 在内容区顶部出现**一行**横幅(同一根因只一行)。「确认」按钮确认后停止闪动,条目保留到清除。
3. 报警面板列:时间、级别图标、内容、原因、建议动作、响应倒计时、状态。
4. **泛滥保护**:任意 10 秒内新增报警超过 10 条时,面板折叠衍生项并显示「报警泛滥」一条元报警。
5. 不在当前视图里的报警,**状态条和顶栏始终显示计数与最高级别**,点击跳到相关视图。
6. 无声音;读屏:P1 用 `aria-live=assertive`,其余用 `polite`。
7. 设计意图:P1 极少、P3 居多(参考 5/15/80 的分布),但小型仿真不按此验收。

### 8.2 GO/NO-GO 席位板

席位:`FIDO`、`GNC`、`PROP`、`LOAD`、`REC`、`RNG`(靶场,`SIM`)、`WX`(气象,`SIM`)。

| 席位 | GO 的条件 |
| --- | --- |
| FIDO | 轨迹偏差在容差带内 |
| GNC | 控制权限 >50% |
| PROP | 推进剂余量 >5 t 且计划发动机全部在线 |
| LOAD | 过载、动压、热流均低于注意线 |
| REC | 制动余量(预测)>150 m |
| RNG、WX | 脚本演示,默认 GO;抽屉「调参」里有开关可切为 NO-GO |

**点名**:在 MECO、分离、再入点火、着陆点火前 10 s,席位板自动「点名」——席位按 400 ms 间隔依次翻成 GO 或 NO-GO,标题显示 `POLL · MECO −10 s`,结束后给出摘要(「全部 GO」或「PROP NO-GO」)。有 NO-GO 就触发 A12。点名不暂停仿真。

## 9. 性能、无障碍、响应式

- **渲染**:单个 `requestAnimationFrame`;每帧只重绘有脏标记且可见的面板;目标 60 fps,1920×1080 下 10 个面板的 JS 耗时 ≤4 ms/帧。
- **数据**:10 Hz;历史用 `Float32Array`;绘制循环内不分配新对象;文字用 `textContent`。
- **无障碍**:每个图表 `role=img`,`aria-label` 是一句概述(例如「高度速度走廊图:速度偏差 −212 m/s,超出容差」),更新频率 ≤1 Hz;聚焦模式提供数据表;焦点环清晰;不靠颜色传达信息;`prefers-reduced-motion` 下去掉位移动画。
- **响应式**:≥1600px 完整布局;1280–1599px 12 列不变、面板高度按比例;<1280px 控制台模式不可用,提示改用紧凑模式;<960px 只有公众版。
- **语言**:所有新文案走 `L(中,英)`。

## 13. 自定义:面板布局编辑器

**结论**:适合,只做在工程版,做成设置里的「布局编辑器」;飞行画面上不拖放;公众版不开放。这是之前讨论过的「小部件可以在设置里更换位置或替换」的概念,本节把它落到控制台模式。

### 13.1 为什么这样限制

- 之前的卡片系统出现过:同一张卡片出现在两个槽位、钉住与自动日程互相冲突、窄屏下无法切换。自由度越高,这类冲突越多。
- 工程师的关注点确实不同:做推进的盯发动机和推进剂,做结构的盯过载和动压,做回收的盯制动余量和热流。
- 所以做法是:**选择和替换放在设置面板里**,飞行画面保持干净。参考 Open MCT 的思路:自定义要有策略限制灵活度。

### 13.2 可自定义的范围

| 区域 | 所属模式 | 格数 | v1 | 说明 |

| 紧凑 · 右区 R | 工程·紧凑 | 4 | 可自定义 | 布局编辑器方案 |
| 控制台 · 总览小部件条 S | 工程·控制台 | 12 | 可自定义 | 本节 §13.4 |
| 控制台 · 总览其余面板 | 工程·控制台 | — | 固定 | 3D 视口、走廊图、全程高度–时间、GO/NO-GO、报警列表、事件日志 |

### 13.5 规则(沿用布局方案并补充)

1. 不在飞行画面上拖放;只在设置面板里选择和替换。
2. 每格只放一个小部件。
3. 同一小部件在同一个「集合」里不重复:紧凑集合 = L + R,控制台集合 = S。两个集合互不影响。
4. 固定优先于自动;2 格小部件不能放在区域最后一格,其下一格不能是固定格。
5. 有阶段语义的小部件(`thr`、`heat`、`brk`)固定显示时,在无意义阶段变暗而不是隐藏。
6. 空格保持空白,其他格位置不重排。
7. 切换模式不会丢失另一个模式的布局。

### 13.6 数据模型与预设(schema 2)
